# 🎉 Event Buddy

> Never attend an event alone.

Event Buddy is a mobile-first web application that helps people discover events and connect with others attending the same event.

Whether it's a concert, festival, sports event, or party, Event Buddy makes it easier to enjoy experiences together.

---

## ✨ Vision

Create a safe and welcoming platform where people can build meaningful connections through shared events.

---

## 🚀 Features (MVP)

- User Authentication
- Browse Events
- Event Details
- Join Events
- Connect with Attendees
- Event Chat
- User Profiles

---
