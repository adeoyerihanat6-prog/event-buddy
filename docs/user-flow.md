# Event Buddy - User Flow Architecture



## 1. Onboarding & Auth Flow
Splash Screen ➔ Onboarding Carousel ➔ Register / Login ➔ Home Feed (`/home`)

## 2. Event Discovery Flow
Home Feed ➔ Click Category or Search ➔ Select Event Card ➔ Event Details (`/event/:id`) ➔ Tap "Going" or "Bookmark"

## 3. Event Creation Flow
Home Feed (Banner or Plus Button) ➔ Create Event Form (`/create`) ➔ Submit ➔ Redirect to Feed / Profile

## 4. Profile & Management Flow
Bottom Nav (Profile Icon) ➔ View Stats & Saved Events ➔ Settings or Edit Profile
